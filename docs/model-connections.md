# 可视化模型连接档案

## 目标与使用

高级设置新增[上下文字符预算](context-budget.md)，可选3万–48万字符。选择后点击启用生效并按账号记住，不等于模型 token 窗口，也不会自动扩大历史选取范围。

精简版入口：顶部「新建 API 连接」→填写名称、地址、模型、密钥→「保存」→「启用」。已保存连接同一「保存」按钮更新当前档案；「保存为新连接」等复制/删除操作仍保留在「连接管理」。请求协议与服务商链接在「协议与服务商」展开；预算选项在「高级设置」。下文原按钮名描述的是保留的次级操作。详见[界面布局](desktop-clean-layout.md)。

在「连接设置」选择现有预设，或修改名称、API 地址、模型 ID、协议和可选服务商链接，输入密钥后点击「保存为新连接」。可保存多份不同模型/服务商连接；「更新当前连接」覆盖当前档案，「删除当前连接」需确认，删除本机密钥不可撤销，不撤销服务商凭证。所有操作按当前本机应用账号隔离。

独立新建入口：页面顶部、连接下拉框右侧的「+ 新建 API 连接」打开空白表单，也可在下拉框选择「新建 API 连接 · 空白表单」。名称、地址、模型、链接和密钥全部清空，不继承旧密钥，协议默认 Chat；按服务商要求可选 Responses。新建草稿不能更新或删除已有档案，也不能在保存之前启用/测试。保存后自动选中新的档案，已有连接不变；新建不会关闭已经启用的模型。

选择已保存连接时，不回显旧密钥；留空沿用，输入新密钥后必须先更新。重开应用会显示上次保存的连接，不自动启用或请求模型；点击「启用当前连接」后用于聊天和简报。保存、启用本身不联网。「测试连接」只向当前地址发送固定 OK 请求，最多64输出token，可能计费，不发送私人报告和兴趣。

无需编辑 model_config.yaml。原 YAML 继续作为预设与 CLI 配置来源；未修改的预设仍支持环境变量或会话密钥。已保存连接独立于 YAML，可以更换服务和模型。当前仅支持已有 Chat Completions / Responses 适配器，不包含 Pi 的全部提供商协议、OAuth 或自动模型目录。API 地址应填写基础路径，例如 https://example.org/v1；完整 /responses 或 /chat/completions 地址按对应协议规范化，避免重复拼接。模型 ID 必须使用服务商提供的准确名称。

## 持久化与安全

元数据及密文存入忽略的 data/research.sqlite3 / model_connections 表。密钥通过 Windows CryptProtectData 加密，CryptUnprotectData 按需解密；采用 Windows 用户范围和应用账号/连接 ID 绑定的 entropy，不使用机器范围标志。读取档案列表不返回密钥或密文。运行时短暂注入独立进程环境变量，创建既有客户端后立即恢复环境；客户端运行期持有必要凭证。无明文落盘、无日志、无配置文件写入、不访问其他软件认证文件。

DPAPI 通常绑定当前 Windows 登录账号与设备，不提供跨设备同步；换设备需要重新输入密钥。应用账号隔离不是抵御同一 Windows 用户或管理员的密码学隔离；有权控制进程/系统的人员仍可能访问运行期凭证。非 Windows 不降级明文保存。API 和服务商链接仅允许无账号密码、查询参数和 fragment 的 HTTPS；HTTP 限本机地址。更换 API 基础地址必须重新输入密钥，不将旧密钥静默发送到新服务。没有自动重试或自动协议切换。

## 实现与验证

database/model_connections.py 管理元数据验证、账号隔离与 DPAPI 边界；desktop/model_settings.py 负责可视化编辑和客户端组装；原核心循环与模型协议保持不变。测试使用虚构密钥，不调用真实模型，覆盖 DPAPI 往返及 scope、跨账号拒绝、更新/删除、地址验证、端点规范化、重开恢复和无自动请求。

参考 Pi 的「选择服务→提供凭证→保存→切换模型」交互，而非复制其明文认证文件：[Pi providers](https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/providers.md)。加密实现依据 [Microsoft CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

验收：项目 Python 3.11 虚拟环境 compileall 通过，完整282项离线测试通过；已检查连接设置与简报中文截图。真实模型 API 未调用，未使用真实密钥；真实服务连通性由用户在界面点击测试验收。
