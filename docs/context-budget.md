# 可选上下文字符预算

## 使用

「连接设置 → 高级设置 → 上下文上限」可选3万、6万、12万、24万、48万字符。初始仍为3万以控制开销；可先选12万排查工具轮次的预算不足。点击「启用」后生效，并在本机账号下记住选择，下次打开恢复选项但不自动启用。无需修改 YAML。更改后不点启用不会修改正在运行的会话预算；重新启用保留既有完成问答。该操作本身不发 API 请求。

## 计量与限制

2026-10-15更新：原生 OpenAICompatibleClient 按实际wire请求JSON字符数计量，避免Responses原生回放与可见消息重复计数；以下dataclass估算仅作为其他模型客户端的保守回退。

预算由 BudgetModel 在每次模型调用前检查，计量是消息（含 wire 回放）与工具定义的 dataclass JSON 序列化字符数，不是精确 HTTP 请求字节数或 token 计数。它包括系统提示、已选择的历史、用户输入、工具说明和当前轮次工具往返。不自动截断提示、引用或工具链。超过预算时阻止该次请求，只显示使用量与上限，不泄露提示内容；允许用户调整后重试。

提高本地字符预算不会扩展模型自身上下文窗口，也不保证中转站接受请求；可能增加 token 费用和延迟。模型请求次数/时间预算、单条输入2000字符、最近3轮历史及8000字符历史选取、证据摘录/输出额度均保持原值，不会因提高上下文而自动发送更多已保存历史或反馈。没有自动压缩、摘要记忆或无限上下文。

## 实现与安全

ResearchSession 的 max_context_chars 参数传给 BudgetModel。桌面在启用时应用当前选择，DesktopRepository 在 desktop_runtime_preferences 中按账号保存一个整数，不包含密钥和个人资料；旧数据库自动创建新表，不改动历史报告。CLI 不新增参数，默认仍为3万；直接使用 Python 接口可传 max_context_chars，范围1–480000的整数。

验证使用离线假模型：相同输入在3万预算被拒、提高后允许；工具定义与工具结果仍计入；详细预算错误穿透安全错误处理；账号隔离、无效值拒绝、窗口重开恢复、界面选择应用到真实 BudgetModel，且启用不触发请求。不使用真实密钥或发送个人数据。
