# 本机账号记忆、恢复码与可配置简报数量

时间：2026-10-18 00:13:23，Asia/Hong_Kong。

## 目的与授权范围

用户需要记住账号、探讨邮箱找回及自己输入新闻数量。经用户明确选择，本轮仅做本机记忆与恢复码，邮件账号服务留后续；没有收集邮箱或部署/购买发信服务。

## 实现

- database/account_security.py：随机设备令牌30天、摘要存储、凭密码验证发放；192位一次性恢复码、验证后事务内重置PBKDF2密码并撤销全部设备。
- desktop/account_access.py、app.py：账号名回填、可选保持登录、DPAPI保护设备令牌、登录页恢复对话框、账号安全入口生成/更换码及取消记住。无明文密码保存或失败降级。
- news_options.py、DesktopRepository：1—100严格整数，默认10，按账号保存。按钮直接输入，不改配置；超过10条默认取消式费用确认。
- session.py、news_pipeline.py、recommendation.py、news_view.py：N贯穿选择、探索配额、正文解读、预算、保存与重新整理，原始分数与缓存不因数量变化失效。不足不凑数，旧报告保持不变。
- 大报告payload超过650000字符时只压缩展示快照，通过独立interpretation_id保留完整校验材料，不提高100万报告限制。

## 限制与同步

不具备邮箱验证、公网认证、在线限流、云同步或数据灾难恢复。密码与恢复码都丢失不能绕过恢复；DPAPI不防同Windows身份恶意程序，SQLite不是服务器安全边界。数量上限100是资源保护，可能显著增加费用，单请求上下文/输出限额不自动增大。
