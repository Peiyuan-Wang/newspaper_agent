# 个性化新闻：画像、内容标签与覆盖

## 目标与当前边界

借鉴搜推系统的画像、物料理解、多路召回、排序和反馈分因，不照搬点击率/停留时间目标。流程为“采集候选→全库AI评分→分层语义画像校正关联性→R/C/I/H三栏共享N条→正文阅读和短解读”，N默认10、1—100。用户大类不编码，同类近义细分兴趣可共享可演化向量；赞踩/弱打开只在类内有界学习，见[语义画像](semantic-interest-profile.md)。缺本地模型时保留标签残差；旧[contextual bandit](contextual-exploration.md)仅兼容非语义且无公共配额路径。没有全网向量召回、协同过滤、在线A/B或CTR训练。

## 画像：主题不等于阅读视角

在“兴趣与领域→细分兴趣与阶段目标”编辑，点击“保存全部”生效。聊天也可请求整理成建议，用户确认后生效；支持既有事件撤销。旧的简单兴趣列表仍可用，不强制迁移。

`research_profiles.interest_units`最多12项，每项字段固定：

| 字段 | 含义和限制 |
|---|---|
| topic / domain | 主题120字符；领域academic/medical/finance/news/general |
| category（可选） | 用户命名大类，最多60字符，只作分组、不编码；缺失则每个主题独立保留未分类，不擅自合并 |
| question / purpose | 具体问题、用途，各180字符，可留空 |
| methods | 偏好方法，最多6条，每条60字符 |
| knowledge_level | beginner/intermediate/expert，按此主题区分水平 |
| priority | 1—5整数，用于日常关注的相对侧重，不是事实重要性 |
| expires_on | YYYY-MM-DD或空；香港日期超过截止日不再用于路由、评分和阅读 |

到期不删除历史，也不自动续期。保存表单属于用户明确设置；模型建议仍是待确认候选。字段、数量、日期与重复主题由`preferences.py`及仓库边界校验；旧档案缺失字段自动补空列表。过期过滤与确认兴趣合并是纯函数，不修改数据库。

评分发送活跃细分兴趣与对应程度规则。阅读上下文包含活跃单元，以及去重后的最多30个简单兴趣+最多12个单元主题；同一篇文章选择命中的问题、方法和用途，而不是将物理研究/AI求职合成泛泛的“科技爱好者”。同一条短解读仍需先说明新闻核心变化、有原文依据；不能为了迎合视角编造贡献。纯写作规则变化不触发兴趣重评分；细分兴趣变化使兴趣缓存失效。

## 内容标签：保守提及，而不是让模型自证

`sources/annotations.py`在标题/摘要中识别有限AI、Agent、LLM、SSG、凝聚态、群论、投影表示、上同调、RL、SFT等概念，以及“分类/发布”的词汇提及。每个标签保存facet、concept、label、field、quote、start/end、version、`basis=mention_only`。英文短词有边界，AI不命中chair。标签不代表该词是论文核心贡献，不代表事实正确，也不代表所有领域已被语义分类。

标签写入账号自己的`news_articles.content.payload.content_tags`，不新建全局私人物料库；旧新闻再进入采集/整理流程时生成，不全库调用模型回填。评分材料只带标签名与原片段；原文跨度留在本地可检查。新闻卡片显示最多4个提及标签，悬停说明其边界。无标签不等于无关。概念表是代码中的有版本词表，当前没有让模型任意扩展/执行代码。

## 多兴趣召回与轮换

订阅简报的日常查询取活跃单元（优先级降序，主题+方法）及简单兴趣，去重后最多12个路由查询；显式查询仍优先。基础领域由档案/查询和单元领域组合。来源有主题时，与查询的AI/物理/数学等有限概念匹配，无主题的通用来源可跨领域补充。

单轮仍最多12源、3路并发，通用来源预留最多2席。显式个人来源优先；其他来源先争取多主题覆盖，再按最久未尝试顺序选取，避免扩容后永远只抓目录前列。明确开启兴趣拓展时，评分后最多30%的展示位置可探索，标明非纯分数前十；它只选已有候选，不增加向量召回，也不保证每轮覆盖所有主题。

`subscription_checks`按账号、来源、端点保存最近尝试时间，失败和缓存复用也计入轮换；成功抓取时间仍独立保存在`subscription_feeds`。失败不能刷新旧池的成功时间，换端点不借旧记录取得可见性。查询审计只保留适用/本轮/待轮换来源数量与时间范围外数量，不保存逐条筛选日志。

## 反馈分因

除漏报、不相关、事实错误外，反馈页与工具支持not_new、too_shallow、too_hard、source_quality、not_now；只记原因，不自动添加排除词、删除兴趣或修改风格。长期调整另提待确认建议。主卡片赞踩和原文打开用于关联性，显式票覆盖弱点击，未点不是负例；重复打开不重复训练。停留时间、历史1—5分不训练。独立“这个方向有用/不相关”仍只属于兼容的离散探索，不混入语义观测。共享仅共享授权审核的信源元数据，不共享画像、向量、新闻库、分数或学习反馈。

## 使用与验证

先建立不同主题单元，例如“SSG→投影表示构造→博士研究→群论→专业”和“AI Agent→工程架构→求职→入门”，再更新订阅简报。选择今天/24小时查看严格时间窗口；检索详情中可以看到轮换覆盖。没有当天新闻不意味着API故障，也不会放松时间凑条数。

离线测试`tests/unit/test_personalized_collection.py`覆盖日期、确认/撤销/隔离、过期、标签证据跨度、边界匹配、轮换、反馈保护、空结果和Qt控件。`test_news_pipeline.py`覆盖分批评分、画像变更缓存、前十名阅读；完整项目测试仍需运行。此轮没有真人数据训练、线上效果实验或真实模型质量验收，不能据测试通过断言推荐质量必然提升。
