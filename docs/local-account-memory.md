# 本机账号记忆与恢复码

## 使用

登录界面记住最近成功登录的账号名，密码不回填。勾选“保持登录30天”后，下次在同一项目数据库、同一Windows用户下可跳过登录。默认不勾选，共用电脑请勿开启。它只恢复本机应用账号，不会自动启用模型或发送网络请求。

“兴趣与领域→账号与安全”提供：

- **生成／更换恢复码**：输入当前账号密码后生成192位随机、一次性代码，只在当次对话框显示。请单独离线保存；新码使旧码失效。不要把码发给模型或其他人。
- **取消记住登录**：撤销当前设备凭证、删除本机自动登录文件；当前窗口继续使用，下次启动需要密码。

忘记密码时，在登录页点“忘记密码·使用恢复码”，输入账号、事先保存的码和两次新密码。成功后码被消耗，所有该账号保持登录凭证撤销；不会直接登录，需正常输入新密码。进入后重新生成恢复码。密码重置不删除兴趣、来源、报告或模型连接。

首次注册不自动生成恢复码，请登录后主动生成。如果密码和恢复码都丢失，当前没有邮件或管理员后门找回能力。数据库或电脑损坏也不能靠恢复码恢复数据，请另做安全备份。

## 实现和存储

`database/account_security.py`沿用ResearchRepository的事务与PBKDF2-SHA256（600000轮、独立盐）。`account_recovery`只存随机恢复码SHA256摘要，重置密码、消耗码、撤销设备在同一事务完成。未知账号或错误代码返回相同文案；重置前做同等密码派生工作，不将本地接口宣称为具备完整在线抗滥用能力。

`remembered_devices`只存256位随机设备令牌的SHA256摘要、账号、UTC到期时刻；绝对有效期30天，不自动无限续期。生成凭证需重新验证密码。`desktop/account_access.py`复用现有WindowsSecretCodec（DPAPI），在`data/desktop-login-<数据库路径摘要>.json`保存账号名与加密令牌，不保存明文密码/令牌。路径绑定数据库，其他Windows用户或不同数据库不能直接复用；损坏、过期、无法解密时回到普通登录，不降级明文。

文件采用同目录临时文件后原子替换；保存失败撤销新令牌，要求取消保持登录后重试。取消记住撤销对应令牌并移除文件；过期令牌在发放新凭证时清理。运行数据位于已有忽略的data目录，不提交Git。姓名式账号名仍可被读取，因为它用于回填，不属于加密凭证。

DPAPI只保护静态凭证，不保证抵御同一Windows登录身份下的恶意程序；本机SQLite不是多租户服务器安全边界。电脑管理员/可改数据库者仍可访问本地资料。没有读取Codex、cc-switch或其他应用认证文件。

## 邮箱服务的边界

本轮按用户选择仅实现本机记忆与恢复码。没有收集邮箱、发验证码、发送邮件或部署账号服务器，也没有把邮箱字符串当作已经验证的身份。

未来邮箱注册/找回应由独立HTTPS账号服务负责：验证邮箱、发送短期单次重置凭证、频率限制/防枚举、重置后撤销会话；发信密钥只在服务端，不能打包进桌面端。账号云端化与兴趣/报告同步是不同功能，仍需单独确认部署、邮件渠道、数据范围和备份策略。

安全设计参考[OWASP密码找回指南](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)，包括随机/单次凭证、验证后改密码和会话撤销；离线恢复码不设邮件重置链接式的短有效期。不声称本机实现等价于完整公网认证服务。

## 验证

`tests/unit/test_account_memory_and_news_count.py`用临时数据库测试账号名回填、设备到期/撤销/损坏、加密失败不降级、单次恢复/更换/跨账号拒绝、密码更新及资料保留；Windows上还实际执行DPAPI保存/恢复/取消测试。没有读取真实账号或向真实邮箱发信。
