# 桌面研究体验升级 · 2026-10-14

目标：修复消息顺序错乱、等待期间全窗口禁用、缺少进度与重试、重复模型整理，以及AI新闻查询进入宽泛新闻源的问题。沿用Python 3.11 / Qt / SQLite和现有双协议模型客户端。

## 参考项目与取舍

参考 [AIHOT 月报](https://aihot.news/monthly) 的导读、重点、栏目和原文入口；查看了 [AIHOT 仓库](https://github.com/KKKKhazix/AIHOT)、`industry/sources.json`、`industry/taxonomy.ts`、`industry/selection.ts`、内容理解提示词、精选文档和架构文档。采用来源与分类配置独立、具体事件优先、来源保留和分层阅读；本版没有引入其双独立评分、向量聚簇、热度计算、定时出刊或整个Node/PostgreSQL服务。

参考 [Pi agent-core](https://github.com/earendil-works/pi/blob/main/packages/agent/README.md) 和 [agent-loop.ts](https://github.com/earendil-works/pi/blob/main/packages/agent/src/agent-loop.ts) 的事件订阅、工具生命周期、停止信号、上下文转换与完成回调。Python实现新增独立RunControl，不依赖Pi SDK、不执行其安装脚本或远程插件。当前显示阶段事件，不是模型逐token流式输出。

## 已实现

- **聊天显示**：每条用户/助手/错误/会话提示是独立控件；助手Markdown渲染，用户文本原样显示。选中旧消息不影响新消息追加。不载入模型给出的图片或HTML。失败和停止在对话内显示，提供重试；等待期间保留正在输入的下一条草稿。
- **任务控制**：Job进度信号连到RunControl。AgentLoop报告模型/工具阶段；来源服务报告开始、完成、失败和筛选数量。计时由界面定时器更新，导航与阅读保持可用；写操作和重复发送暂时禁用。聊天区与窗口底部都有停止入口。
- **中止边界**：协作式停止，在请求与工具前后检查。不强杀线程；当前HTTP请求可能等到超时才结束，页面明确显示收尾状态。停止后不发后续模型请求，不把迟到回答写入对话；已保存的个人反馈与来源修改不自动撤销。任务总预算150秒，边界检查生效；系统DNS/当前阻塞HTTP本身不被即时中断。
- **检索速度**：最多3个来源用独立线程并行读取，各适配器拥有独立缓存。结果按来源路由顺序汇总，避免并行完成顺序改变最终排序；单源失败不让整个任务失败。
- **减少重复请求**：桌面默认“快速研究模式”；工具批次得到有效资料后直接转到独立综合阶段，常见一次搜索从3次模型请求减少到2次。复杂补查可在设置取消快速模式，恢复完整多轮工具循环。无模型的简报仍是零模型请求。
- **上下文与恢复**：模型上下文最多保留8000字符完整问答对，UI进度/错误提示不进入模型。最近3轮完成的问答按账号保存，重新打开恢复；新对话清空当前保存的上下文。失败、取消不保存新问答。切换模型保留当前完成对话。
- **新闻配置**：`config/editorial.yaml` 配置栏目、匹配词、默认30天窗口；界面可选7/30/90天、栏目、相关性或最新顺序、要点/标准/展开阅读。分类是透明词法规则，不宣称语义分类已经校准。相同规范化标题折成一件信息，保留所有来源链接；不同标题的同一事件仍可能重复。
- **AI来源**：新增OpenAI官方RSS、Hugging Face官方博客和TechCrunch AI RSS，来源元数据使用topics区分主题。AI/agent/LLM查询优先专业源；普通查询不自动流入AI源。仅AI专业feed可提供“AI”主题背景，agent等细分词仍须出现在内容里。RSS先对全部feed候选做主题与日期检查，再截取预算，避免宽泛AI条目挤掉智能体条目。
- **时间意图**：聊天工具保留用户原话的近期要求，即使模型把查询改写成纯英文主题；识别“过去一周/过去一个月”等滚动窗口。明确日期仍来自来源，未知日期不当作当天发布。
- **连接与预算**：设置页可选20/30/45秒等待和1800/4096输出预算上限，启用时生效；实际额度仍受provider配置约束。密钥仍为本次进程环境变量，不保存进对话或配置。测试连接仍是单独的可选请求。

## 模块关系

`desktop/chat_view.py`：独立消息控件；`desktop/app.py`：导航、任务事件与操作状态；`agent_core/runtime.py`：与Qt无关的取消和进度；`AgentLoop`：可选control与finish_after_tools钩子；`research/session.py`：工具执行到综合的编排；`research/service.py`：并行检索；`synthesis/editorial.py`：分类与确定性同标题分组；`database/desktop_repository.py`：按账号保存评分和最近问答。

没有新增依赖。CLI和教学循环默认保持完整AgentLoop行为；桌面快速模式只跳过拿到证据之后的重复自由文本回答，不跳过已请求的反馈/来源工具批次。跨账号来源/报告/评分边界沿用原实现。

## 验证和实际限制

离线回归包含：旧消息选中后发送仍按顺序追加；等待时导航与下一条草稿可用；中止后迟到回答不提交；三来源用Barrier验证确实并行；快速研究只使用一次规划与一次综合；近期意图不被模型改写丢失；对话只恢复本账号；同标题合并保留所有链接。Qt离线渲染检查聊天与配置页。

真实来源小规模验收，各源最多2条：OpenAI与TechCrunch返回有效匹配；Hugging Face第一次可读取但当时没有通过30天筛选，第二次请求超时。失败会独立显示；不保证每个网络环境都能访问这些网站。测试没有请求真实模型或Tavily，没有读取桌面应用中输入的密钥。模型延迟和回答质量仍需使用界面中的实际provider验收。

完整语义事件聚类、独立来源热度、双模型精选校准、自动刊期、逐token流式、完整聊天档案检索属于后续独立模块；本版不把关键词分组与短摘录冒充这些能力。

验收：完整测试263项通过，compileall通过；新增7项回归覆盖以上关键操作。`git diff --check`只有此前 model_config.yaml 第60行末尾空行提示，无关配置未更改。真实模型和收费搜索请求均为0。
