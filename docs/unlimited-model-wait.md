# 模型请求不限时

## 目标与用法

按用户要求移除桌面端的模型等待上限，而非把45秒改成另一个较大数字。重启应用并重新启用模型连接后生效；连接设置不再提供20/30/45/90/120秒选项，显示“模型等待不限时”。聊天、简报AI整理和连接测试均使用此策略。

## 实现与配置

保存连接的OpenAICompatibleSettings.timeout=None；预设连接调用create_research_model(request_timeout=None)，覆盖YAML旧timeout，无需用户编辑配置。HTTPX连接、读取、写入、连接池等待均为None；read_bounded不执行总响应计时截断。桌面RunControl.max_seconds=None、ResearchSession内BudgetModel.max_seconds=None，避免150秒或240秒的外层任务预算仍截断长回复。请求详情同时显示wait_policy=不限时及active_wait_seconds=null。

输入消息与输出协议未改变；不扩大上下文、输出token、模型请求次数或工具次数，仍限制响应大小4MB。502/503/504及remote_protocol/read_error响应中断共享最多两次HTTP尝试，不无限重发；格式错误等照常报告。专业来源和搜索HTTP请求保留原有安全超时，不将第三方资料抓取改为无限等待。底层通用客户端、独立RunControl及CLI工厂仍支持原有限时参数，以兼容其他调用方；桌面不使用这些时间预算。

## 取消与安全边界

继续提供停止任务；退避、数据块与操作阶段之间检查取消。但同步HTTP在服务端完全不回包时，停止操作不能立即打断阻塞读取，任务可能一直等待，需要对方返回或断开后才能收尾；不能声称即时停止。无客户端时限不等于保证成功：服务商、网关、代理或操作系统仍可主动超时或断开。取消不撤销服务商计费，不回滚已完成工具操作。不自动发送额外个人资料，不修改密钥。
