# 知闻桌面工作台

[新闻简报](two-stage-news.md)先为新闻库分批评分，再合成关联性/可信参考/重要性/报道热度，提供“个人推荐 / 大事件 / 今日热榜”，切换不调用模型。“最多N条”按钮1—100（默认10）是三栏共享去重解读预算；不足不凑数，超过10先确认费用，数值按账号保存。主卡片显示推荐及分项分数、互斥可撤回赞踩、原文打开计数，解读折叠；“指标权重”按账号保存三栏权重与反馈学习开关，也可清除新反馈。旧星级保留于历史评分，不训练新机制。无模型仅待评分个人预览，旧报告不自动改写。详见[四信号实际边界](multisignal-ranking.md)与[数量设置](news-output-limit.md)。

[分类信源采集](subscription-news.md)提供订阅池、领域筛选、通用来源跨领域参与和按主题覆盖/最久未尝试轮换；可选应用运行期间30分钟无模型采集，默认关闭。时间可选[香港今天、过去24小时、7/30/90天](today-news-and-expanded-sources.md)；“兴趣与领域→细分兴趣与阶段目标”分别编辑问题、用途、方法、程度、优先级与期限，详见[个性化与覆盖](personalized-news-routing.md)。

“兴趣与领域→兴趣拓展·可选”控制本账号探索比例、推荐温度、离散邻域范围及反馈敏感度，默认关闭。启用后日常简报少量条目标“兴趣拓展”，在评分页用独立“这个方向有用/不相关”反馈或撤回；普通星级不训练。设置内可确认清除学习。具体算法、条件概率和非向量限制见[上下文兴趣探索](contextual-exploration.md)。

AI整理增加[校验与修正循环](synthesis-repair.md)：格式或引用未通过时最多修正2轮，展示进度、轮数和失败原因；有界草稿按当前账号保留，未通过时不作为正式结论展示。

2026-10-15更新：[模型等待不限时](unlimited-model-wait.md)。移除等待秒数选项和桌面外层任务时限，重启并重新启用连接生效；服务商仍可能超时，阻塞读取期间不保证即时取消。

原生 Windows/Python Qt 界面，复用既有 ResearchSession、来源适配器和账号数据库，通过可选运行事件连接界面与核心循环。

“兴趣与领域→兴趣分类与语义画像”提供大类—细分向量树、关联反馈数和偏转角度。编辑分类时可将旧关注主题导入草稿再逐项设置category，保存才生效；类别名不被编码。准备本地模型需显式下载约220MB公开文件，之后CPU离线运行，无额外Key。按当前反馈重建或下次生成简报会更新细分偏好，历史报告不自动修改；关闭反馈学习只用种子，关闭语义路径保留原标签校正。相似度不是点击概率，详见[算法与操作](semantic-interest-profile.md)。

## 启动

“AI重新整理”默认只补未完成或失效的评分/解读，复用有效内容，不重新搜索；评分进度显示已完成/全库条数。检索详情可查看评分复用/补评数、服务端已报告Token及缓存/推理子集，缺失用量明确未知。重要性校验错误不会丢弃正确兴趣分，未完成全量时仍不假称全库前N，见[评分与K/V缓存](efficient-news-scoring.md)。

在项目根目录双击 `启动知闻.cmd`，或使用项目虚拟环境运行 `python -m newspaper_agent.desktop`。先执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt` 安装依赖。PyCharm 解释器仍为项目 `.venv` / Python 3.11。当前为源码运行版，不是独立安装包；不能只复制启动文件到其他电脑。

首次创建本机账号，已有CLI账号可登录，共用data/research.sqlite3。首个账号管理共享来源。账号名记住，密码不回填；勾选保持登录30天后同Windows用户自动恢复。切换账号先在“兴趣与领域→账号与安全”取消记住，再关闭重启。该入口可验证当前密码生成一次性恢复码；登录页以事先保存的码重置并撤销所有设备。没有邮件或云同步，见[本机安全说明](local-account-memory.md)。

## 七个入口

- 新闻库：按公司、模型和方向查看本机已存新闻，搜索历史标题/摘要、分页及按报道时间正反序浏览；事件可查看进展时间线与原文证据。旧新闻先按标题关联，正文主体与事件仅覆盖完成新解读的条目。打开页面不调用模型或原网页，详见[正文阅读与历史专题](news-reading-and-library.md)。

“兴趣与领域”新增阅读用途、知识水平、表格/卡片/提纲、表达规则、术语约定与待确认建议。点击“让AI访谈我的兴趣与表达偏好”生成聊天开场；用户点击发送后才请求模型。候选列表显示修改前后值，确认或拒绝后同步有效档案。详见[两套个性化策略](interest-and-expression-strategies.md)。

- 今日简报：输入关键词、选择领域/时间并手动更新；左栏最近100份报告，右栏三个推荐栏目。大事件限有依据的近7天候选，今日热榜限香港今天多组织报道覆盖，空栏不凑数；不是平台热搜或完整全网大事。赞踩和弱原文打开仅校正已确认兴趣标签的关联性，不改变长期领域、来源可信度或重要性；重复打开不反复放大学习。历史1—5分保留、不训练新机制。卡片≥50%可见1秒才记曝光，不代表阅读。
- 研究对话：启用模型后，沿用工具循环讨论遗漏、修改明确兴趣、补查和发现来源；最多6次模型请求/轮。未连接模型不能自然语言对话，但可真实搜索。
- 兴趣与领域：选择五类领域，每行填写一个具体兴趣或排除词，选择阅读详略。显式排除词会影响过滤，修改可在反馈记录中撤销。
- 反馈与改进：六类反馈与自由文本；直接保存反馈不猜测偏好，进一步分析请在研究对话讨论。撤销仍遵循现有版本保护。
- 信息来源：浏览内置、个人与共享来源；提供公开网站发现候选，验证后启用；个人贡献、管理员发布均确认。共享只公开来源元数据，不共享报告与兴趣。
- 连接设置：可视化编辑连接名称、API地址、模型ID、Chat/Responses协议、服务商链接；「保存为新连接」或「更新当前连接」按本机应用账号保存档案，密钥使用 Windows DPAPI 加密，下次登录无需重填。保存和启用不发请求，测试连接仅发送一次固定小请求；删除需确认。未修改的 YAML 预设仍支持仅本次使用环境变量/会话密钥。详见[连接档案与安全边界](model-connections.md)。Tavily 仍通过环境变量配置。

2026-10-14 阅读排版更新：每份简报采用标题、信息数量、分栏主题、编号重点、短摘录和依据链接；中文阅读增加行距、段落间距和表格留白。关键词、时间筛选、覆盖提示、隐藏条目与来源失败信息放入默认折叠的「检索详情」，不再插入简报开头。主张的适用条件、不确定性和原文阅读边界仍保留；来源速览不冒充 AI 综合结论。无结果时显示简洁空状态和下一步建议。历史报告原数据不删除。

## 实现、安全与限制

界面位于 `desktop/`；独立 `database/desktop_repository.py` 管理评分、最近问答并校验归属。后台线程执行网络操作，处理期间禁止写操作重入，导航阅读和草稿输入可用；关闭前需要请求停止并等待当前请求收尾。异常不显示底层请求和凭证。外链仅允许 http/https，浏览器不会加载 file/javascript 链接。文本来源使用纯文本标签，不执行网页脚本。

不提供自动定时日报、云端账号同步或独立 exe 安装包。账号仅保护应用访问，不加密本机 SQLite；能访问数据库文件的本机管理员仍可读取资料。赞踩/打开在模型就绪时有界更新细分语义向量，否则保留标签残差；不训练编码器、QKV或CTR模型。可信度仅来源先验、热度仅报道覆盖，重要性仅材料估计；真实推荐效果不由离线测试保证。Tavily仍为可选配置。

验证：项目虚拟环境执行 compileall 和 pytest；Qt 使用 offscreen 进行导航、保存与报告展示测试。界面可在不联网、不调用模型的情况下验证。Qt 后台任务采用官方 [QThreadPool/QRunnable](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QRunnable.html) 模式。
