# 桌面界面精简

## 目标

默认只展示日常操作和内容，减少同级按钮、口号、技术说明及重复提示。沿用原生 Qt 与现有后台，不调整检索、模型协议、账号、密钥或学习策略。

## 页面与入口

- 全局：窄侧栏、无导航序号、短标题，移除英文标语和大段副标题。统一中性色底、绿色强调、紧凑按钮与轻量文字入口。停止任务仅在后台运行时出现在底栏，聊天不重复展示停止按钮；重试仅在失败后出现。
- 简报：搜索框、领域、时间和更新保留。阅读/评分变成紧凑标签，反馈入口保留；栏目、详略、排序收进「筛选与阅读选项」，检索详情与结果数量放在同一行。证据条件和不确定性不隐藏。
- 模型连接：顶部明确「新建 API 连接」；默认只展示名称、地址、模型、密钥，以及保存/启用/测试。统一「保存」判断新建或更新；协议、服务商链接在「协议与服务商」，复制/更新/删除/关闭在「连接管理」，预算和 Tavily 说明在「高级设置」。删除和共享仍需确认，测试费用提示在按钮说明中，保存/启用不联网。
- 兴趣：领域、兴趣、排除词及保存保留；用途、知识水平、结构与术语等在「阅读与表达偏好」。待确认建议入口始终显示数量，展开查看和确认；不自动应用。
- 来源：发现来源为主要操作；验证、启停、共享与发布在「管理选中来源」。权限与确认不改变。

折叠入口使用 +/− 提示状态。默认收起，当前窗口可随时展开，修改的值在折叠后不会丢失。无跨设备布局同步。操作失败仍显示具体安全提示，不将冗余说明移除理解为删除安全边界。

## 验证

离线测试检查新建仍可用、折叠默认状态、展开可见、统一保存的新建/更新、后台任务停止/失败重试及原有功能回归。使用虚构资料与测试密钥渲染中文截图，不调用真实模型，不修改真实用户数据。

验收：项目虚拟环境 compileall 通过，完整284项测试通过；已检查简报、连接设置和兴趣页中文截图。保留仓库原有 model_config.yaml 末尾空行提示，未修改无关配置。
